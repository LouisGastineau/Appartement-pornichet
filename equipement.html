Guide des équipements de l'appartement

Retrouvez ici toutes les informations pratiques pour utiliser les équipements de l'appartement.

Les notices de chaque appareil sont dans le premier tiroir de gauche du bureau.

Informations de connexion WiFi :

  • Nom du réseau (SSID) : Vous trouverez le nom du réseau sur l'étiquette du routeur situé dans le salon
  • Mot de passe : le mot de passe est disponible sur la Box placée sous le téléviseur.

En cas de problème :

  • Vérifiez que le routeur est bien allumé (voyant lumineux vert)
  • Redémarrez votre appareil pour reconnecter
  • Si le problème persiste, contactez l'agence

Comment utiliser le four :

  • Préchauffage : Tournez le bouton de température sur la valeur souhaitée et le sélecteur de fonction sur le mode approprié
  • Modes disponibles : Chaleur tournante, sole (bas), voûte (haut), grill
  • Température : Le four peut chauffer de 50°C à 250°C
  • Temps de préchauffage : Comptez environ 10-15 minutes pour atteindre la température

Conseils d'utilisation :

  • Utilisez la chaleur tournante pour une cuisson uniforme
  • Placez la grille au niveau souhaité avant de préchauffer
  • Nettoyez les grilles et la plaque après utilisation
  • Éteignez complètement le four après usage en remettant tous les boutons sur 0

Instructions pour le lave-linge/séche-linge :

  • le mode d'emploi est posé sur la machine à laver

Après utilisation :

  • Laissez le hublot entrouvert pour aérer le tambour
  • Essuyez le joint en caoutchouc pour éviter les moisissures

Instructions pour la douche :

  • Après utilisation, passez la raclette sur les vitres afin d’éviter l’accumulation de calcaire.

Consignes de sécurité :

  • N'utilisez jamais de récipients métalliques ou avec bordures métalliques
  • Privilégiez les contenants adaptés micro-ondes (plastique, verre, céramique)
  • Couvrez les aliments pour éviter les projections
  • Nettoyez l'intérieur avec une éponge humide après utilisation

Organisation du réfrigérateur :

  • Zone la plus froide (haut) : Produits laitiers, viandes, poissons
  • Zone intermédiaire : Plats cuisinés, restes
  • Bac à légumes (bas) : Fruits et légumes frais
  • Porte : Boissons, sauces, œufs
  • Congélateur : Produits surgelés (température -18°C)

Bonnes pratiques :

  • Réglez le thermostat entre 3°C et 5°C pour le frigo
  • Ne surchargez pas les étagères pour permettre la circulation d'air
  • Conservez les aliments dans des boîtes hermétiques
  • Vérifiez les dates de péremption et ne laissez pas de restes trop longtemps
  • Nettoyez les éventuels déversements immédiatement

Utilisation :

  • L'accès à la terrasse doit se faire exclusivement à partir de la porte fenêtre de gauche.
  • L'arrosage automatique est programmé. Merci de ne pas fermer le robinet.
  • Veillez à rentrer les coussins chaque soir. Faute de quoi, ils seront humides le lendemain à cause de la rosée.
  • ATTENTION : en cas de vent fort ou de tempête, rentrer l'ensemble du mobilier dans l'appartement (sauf la table haute).

Utilisation des volets roulants :

  • Chaque volet dispose d'une télécommande posée à proximité de la fenêtre (boitier blanc).
  • Utilisez la flèche du haute pour lever le volet, celle du bas pour le baisser et le bouton "my" pour stopper le volet ou tamiser la lumière.
  • Une télécommande centralisée est également à votre disposition à gauche de la télévision (même fonctionnement que les télécommandes individuelles).
  • ATTENTION : en cas de vent fort, les volets doivent être totalement ouverts ou fermés.

Entretien quotidien :

  • Nettoyez les surfaces après chaque utilisation
  • Essuyez immédiatement les déversements
  • Aérez la cuisine après avoir cuisiné
  • Vérifiez que tous les appareils sont éteints avant de quitter l'appartement

En cas de problème :

  • Vérifiez d'abord le disjoncteur dans le tableau électrique : le tableau est situé derrière le panneau en bois dans le couloir d'accès au salon. Il suffit de le lever de quelques centimètres vers le haut et le tirer vers vous (attention le panneau est lourd et il faut éviter de toucher le plafond).
  • Le tableau électrique est dans l'armoire métallique du haut.
  • Après avoir remis en marche les disjoncteurs et/ou l'électricité, remettre le panneau en bois en appuyant la partie haute sur le rebord de l'armoire électrique. Des aimants permettent de tenir l'ensemble.
  • N'hésitez pas à contacter l'agence du Casino pour toute question sur le fonctionnement des appareils électriques ou problème technique.
  • En cas d'urgence, les numéros importants sont sur la page Contacts

Profitez pleinement des équipements mis à votre disposition pour un séjour confortable !
